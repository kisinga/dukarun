# Research archive

Non-production experiments and sample artifacts:

- `product-recognition-spike/` — browser embedding/matching proof of concept and photographed
  product dataset.
- `model-samples/` — historical recognition model files.
- `legacy-images/` — unreferenced implementation-era image material.

These files are not shipped by an active app and are not an implementation dependency. Promote
an experiment back into `apps/` only through a documented product/architecture decision.
