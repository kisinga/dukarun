# Suppliers

Keep each supplier's details, terms, purchases, payments, and unpaid balance in one account.

## Common actions

- [Creating a supplier](creating-a-supplier.md)
- [Recording a credit purchase](../purchases/recording-a-credit-purchase.md)
- [Recording a supplier payment](recording-a-supplier-payment.md)

## Understand the balance

A credit purchase increases the amount you owe the supplier. A supplier payment reduces it.
