# Generating product barcodes

## Why this matters

A unique barcode lets a scanner or device camera add the correct variant and selling unit to a
sale quickly. A single item and a pack of that item need different active barcodes.

## Before you start

Create the product and its variants first. If the supplier already prints a reliable barcode on the
item, use that code instead of generating another one.

## Steps

1. Open **Products**, then choose **Print labels**.
2. Review variants marked **Missing** or **Ambiguous**.
3. Choose **Generate missing barcodes**.
4. Confirm the variants that need a Dukarun barcode.
5. Review the generated codes, choose the label layout, and print.
6. Attach each label to the matching item or shelf position.

## What changes in Dukarun

Each selected variant receives a unique code. Scanning that code on the Sell screen can add the
matching variant to the cart.

## Printing pack labels

Set the **Pack barcode** in the product editor before printing. Automatic barcode generation
assigns codes to base variants; it does not generate pack barcodes. Only active packs with a selling
price appear among the printable selling units.

Open **Print label** for a variant, then choose the desired unit under **Label for**. The pack label
includes the pack name and contents. Catalogue printing includes ready labels for both individual
units and sellable packs. Test that a pack label adds one pack, with its full contents and configured
pack price, before printing more labels.

## If something does not look right

- Do not print a barcode marked **Ambiguous**. The same code is linked to more than one variant.
- Correct a duplicate code or generate a unique Dukarun barcode before printing.
- Test one label on the Sell screen before printing a large batch.
- Retire a saved pack before reusing its barcode for a replacement. Completed documents retain the
  original pack identity. See [Setting up and using packs](using-product-packs.md).
