# Selling

Add products to a sale, check the total, and record how the customer will pay. Take payment now for
a cash sale. Use a credit sale only when an approved customer will pay later.

## Common actions

- [Making a cash sale](making-a-cash-sale.md)
- [Selling by scanning a barcode](selling-by-scanning-a-barcode.md)
- [Making a credit sale](making-a-credit-sale.md)

## After the sale

- For a credit sale, [receive the customer's payment](../customers-and-credit/receiving-a-customer-payment.md)
  when they pay later.
- Use [Money & Reporting](../money-and-reporting/README.md) to see how the sale changed stock, cash,
  customer balances, revenue, cost of goods sold, and margin.
