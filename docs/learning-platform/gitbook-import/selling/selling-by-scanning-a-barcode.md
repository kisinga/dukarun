# Selling by scanning a barcode

## Why this matters

Scanning is faster than searching and reduces the chance of adding the wrong product variant.

## Before you start

The variant must be active, available for sale, and linked to one unique barcode. Test newly printed
labels before using them during a busy shift.

## Steps

1. Open **Sell**.
2. To use a connected barcode scanner, place the cursor in **Search or scan barcode**, then scan.
3. To use the device camera, choose **Scan**, allow camera access, and hold the barcode inside the
   frame.
4. Check that Dukarun added the correct variant and quantity.
5. Continue with the normal cash or credit checkout.

## What changes in Dukarun

The matching product variant appears in the current sale. Scanning changes how you find the item,
not how payment or stock is recorded.

## If something does not look right

- If more than one variant matches, open **Products** and correct the duplicate barcode.
- If nothing happens, reconnect the scanner or allow camera access when prompted.
- If the wrong item appears, stop and correct the barcode before completing the sale.
